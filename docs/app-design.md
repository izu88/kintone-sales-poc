# アプリ設計

## アプリ名

営業商談管理

## フィールド

| 項目 | 種類 | フィールドコード |
| --- | --- | --- |
| 会社名 | 文字列（1行） | `company_name` |
| 担当者名 | 文字列（1行） | `contact_name` |
| 商談名 | 文字列（1行） | `deal_name` |
| 流入経路 | ドロップダウン | `lead_source` |
| 顧客課題 | 文字列（複数行） | `customer_issue` |
| 商談メモ | 文字列（複数行） | `deal_memo` |
| 担当営業 | ユーザー選択 | `sales_rep` |
| 商談確度 | ドロップダウン | `probability` |
| 次回アクション | 文字列（1行） | `next_action` |
| 次回対応日 | 日付 | `next_action_date` |
| 金額 | 数値 | `amount` |
| 失注理由 | ドロップダウン | `lost_reason` |

## プロセス管理

```text
新規
↓
初回対応
↓
ヒアリング
↓
提案
↓
商談中
├─ 受注
└─ 失注
```

## 一覧

- 自分の商談
- 次回対応期限あり
- 商談中
- 受注
- 失注
- 全商談

## JavaScriptカスタマイズ

### 期限超過警告

レコード詳細画面を表示した際、次の条件を満たす場合に
kintoneの詳細画面上部へ警告を表示します。

- `next_action_date` が今日より前
- ステータスが「受注」「失注」ではない

表示文言:

```text
⚠ 次回対応期限を過ぎています
```

警告表示には `kintone.app.record.getHeaderMenuSpaceElement()` を利用します。
フォーム上のスペースフィールドは使用しないため、警告がないレコードでは
フォーム上に不要な余白が残りません。
