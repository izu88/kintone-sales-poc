# ポートフォリオ用スクリーンショット

README / ポートフォリオ資料では、実在情報・APIトークン・環境URLが映らないよう注意してください。

## 推奨スクリーンショット

1. **商談一覧**
   - 複数の架空商談が見える
   - 会社名 / 商談名 / 商談確度 / 次回対応日 / ステータスが確認できる

2. **商談詳細**
   - 主要フィールドが確認できる
   - 架空データのみ使用

3. **期限超過警告**
   - 「⚠ 次回対応期限を過ぎています」が表示された状態

4. **プロセス管理**
   - 「新規 → 初回対応 → ヒアリング → 提案 → 商談中 → 受注 / 失注」が分かる画面

5. **受注バリデーション**
   - 金額未入力でエラーが表示された状態

6. **失注バリデーション**
   - 失注理由未入力でエラーが表示された状態

7. **REST API実行結果**
   - `npm run api:list` の結果
   - APIトークンやサブドメインは映さない
